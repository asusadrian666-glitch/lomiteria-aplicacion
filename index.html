🚀 Cómo Publicar en GitHub Pages

1. Crear repositorio en GitHub: Entra a github.com/new y crea un repositorio público (ej: app-lomiteria).

2. Subir los archivos: Sube todos los archivos de esta carpeta (index.html, carpetas css, js, assets, icons, manifest.json y sw.js).

3. Activar GitHub Pages: En tu repositorio ve a Settings > Pages. En Branch selecciona main (o root) y pulsa Save.

4. ¡Listo!: En 1 minuto tendrás un enlace HTTPS gratis (ej: https://tu-usuario.github.io/app-lomiteria/) que puedes abrir en tu celular y pulsar "Añadir a pantalla de inicio".
